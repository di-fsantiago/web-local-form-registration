# web-local-form-registration
Aplicação web para registro de cadastros com armazenamento local no navegador.

## 02. Tecnologias Utilizadas
- HTML5
- CSS3
- Javascript 

## 03. Como Instalar e Executar
Não é necessário instalar nenhuma dependência.

1. Clone este repositório:
   ```bash
   git clone https://github.com/di-fsantiago/web-local-form-registration.git
   ```

2. Acesse a pasta do projeto:

   ```bash
   cd web-local-form-registration/cadastro-formulario-2
   ```

3. Abra o arquivo `index.html` em seu navegador.

## 04. Exemplo de Uso ou Demonstração
Ao abrir a página (index.html), você encontrará um formulário com campos para foto, nome, endereço, telefone, e-mail, nacionalidade e naturalidade.

Cadastrar: Após preencher corretamente todos os campos (como utilizar o formato @dominio.com no e-mail), clique no botão de cadastro. As informações serão salvas no LocalStorage e exibidas na tela, logo abaixo do formulário.

* Limpar: O botão de limpeza remove os dados digitados que ainda não foram salvos.
* Excluir: É possível remover um registro salvo, o que apagará os dados da memória local.

> Nota: Caso recarregue ou saia da página, as informações salvas no armazenamento local não permanecerão visíveis, para realizar a visualização ou exclusão delas, será necessário realizar um novo cadastro.
